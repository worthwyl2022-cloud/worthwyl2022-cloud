## Convertible Cranium Ecosystem

Convertible Cranium is a governed control-plane and evidence substrate for AI-enabled actions. Its architecture separates authority decisions, attestation, receipt integrity, recovery, provider integration, and public demonstration into explicit layers.

- **Convertible Cranium Core** — authority transitions and evidence requirements.
- **Convertible Cranium Synapse** — attestation and risk-boundary contracts.
- **Convertible Cranium Kernel** — receipt integrity, replay controls, recovery, and governed memory.
- **Convertible Cranium Ultra** — integrated operator and verification platform.
- **Convertible Cranium Engineering** — the WorthWyl Media software and engineering division through which the ecosystem is presented.

The public repositories document the architecture and evidence boundaries. Proprietary implementation repositories remain private for controlled acquisition diligence.
