# Convertible Cranium Brand Architecture

## Canonical naming

| Layer | Canonical name | Meaning |
|---|---|---|
| Legal entity | **Convertible Cranium Engineering LLC** | Intended engineering, licensing, and platform company name; legal formation and ownership remain separate diligence matters |
| Infrastructure platform | **Convertible Cranium** | The governed AI infrastructure and ecosystem |
| Dual-engine substrate | **Convertible Core + Convertible Synapse** | Core governs authority and action; Synapse supplies bounded cognition and evidence |
| Continuity pillar | **Convertible Miracle Memory** | Governed continuity, journal integrity, quarantine, promotion, and recovery |
| Containment pillar | **Convertible COMA** | Containment, action freeze, evidence capture, snapshotting, and controlled resumption |
| Product family | **Convertible [Product Name]** | Product naming convention for new platform-native products |

## Repository identity rule

Existing repository names such as `cranium-kernel`, `cranium-synapse`, and historical `Cranium-Core-` lineages are preserved as technical identifiers so links, provenance, imports, and acquisition records remain stable. Their current product-facing names are established by documentation and repository descriptions:

- `cranium-kernel` is the canonical implementation of **Convertible Core**.
- `cranium-synapse` is the canonical contract surface for **Convertible Synapse**.
- Miracle Memory and COMA are foundational capabilities currently implemented in the Core repository.
- Supporting, historical, demo, and application repositories remain ecosystem surfaces and do not become alternate authorities through branding.

## Writing rule

Use **Convertible Cranium** for the platform. Use **Convertible Core** and **Convertible Synapse** for the two engines. Use **Convertible Miracle Memory** and **Convertible COMA** for the supporting pillars. Use the original repository slug when referring to a GitHub location, source path, commit, package, or historical artifact.

Branding does not by itself establish ownership, trademark rights, entity formation, inventorship, or assignment. Those matters require separate legal records.
